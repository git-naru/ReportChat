# DRD — ReportChat 디자인 요구사항

| 항목 | 내용 |
|---|---|
| 문서 버전 | 1.0 (2026-10-20) |
| 대상 | 서버 버전 `public/`, 아티팩트 버전 `artifact/reportchat.html` |
| 관련 문서 | [PRD](PRD.md) · [TRD](TRD.md) · [인수인계](HANDOVER.md) |

## 1. 디자인 원칙

1. **문서가 주인공이다.** 화면 대부분을 페이지에 쓰고, 도구는 한 줄로 모은다. 페이지는 항상 흰 바탕(원본 그대로)으로 보인다.
2. **누가 무엇을 했는지 색으로 안다.** 사람마다 고유한 펜 색, 커서 이름표, 아바타 테두리 색을 같은 색으로 맞춘다.
3. **바로 쓸 수 있다.** 첫 화면에서 할 일(파일 올리기)이 하나만 보이고, 들어오자마자 펜이 선택되어 있다.
4. **다른 사람의 움직임이 보이되 방해하지 않는다.** 커서는 작게, 오래 멈추면 흐려진다.

## 2. 화면 구성

```
┌───────────────────────────────────────────────────────────────┐
│ ☰ ReportChat  🔗초대 링크 복사  ● 실시간 연결됨      (A)(B)  (나) │  헤더 52px
├──────────────┬────────────────────────────────────────────────┤
│ [파일 올리기] │ ↖ ✎ ▭ T ⌫ │ ●●●●●●●●● │ • ● ⬤ │ ↶ ↷ │ 🗑 ⤓      │  도구 모음
│ 안내 문구     ├────────────────────────────────────────────────┤
│              │                                                │
│ [문서] 보고서 │            ┌──────────────────┐                 │
│ ┌──┐ ┌──┐    │            │   페이지 이미지    │  ← 무대(회색)     │
│ │1 │ │2 │    │            │   + 필기 레이어   │                 │
│ └──┘ └──┘    │            └──────────────────┘                 │
│ 문서 목록 250px│                                                │
│              ├────────────────────────────────────────────────┤
│              │ ‹ 보고서.pptx · 1 / 3 ›     [함께 보기]  − 100% + │  쪽 넘김 바
└──────────────┴────────────────────────────────────────────────┘
```

| 영역 | 내용 |
|---|---|
| 헤더 | 목록 열기/닫기, 로고, 초대 링크 복사, 연결 상태, 다른 참여자 아바타(최대 8 + `+N`), 내 이름·색 (누르면 변경) |
| 문서 목록 | 파일 올리기 버튼, 붙여넣기 안내, 최근 문서가 위. 문서마다 종류 배지·이름·삭제(×, 마우스를 올리면 표시)·쪽 썸네일 2열 |
| 도구 모음 | 도구 5개 │ 색 │ 굵기(또는 글자 크기) │ 되돌리기·다시 실행 │ 지우기 메뉴·PNG 저장. 그룹은 세로 구분선 |
| 무대 | 회색 바탕 가운데 페이지(그림자). 넘치면 스크롤 |
| 쪽 넘김 바 | 이전/다음, `문서명 · 현재 / 전체`, 함께 보기 스위치, 확대/축소·맞춤 |

### 상태별 화면

| 상태 | 표시 |
|---|---|
| 문서 없음 | 무대 가운데 점선 카드: 업로드 아이콘, "공유할 파일을 올려 주세요", 형식 안내, [파일 선택] |
| 변환 중 | 문서 목록에 스피너 + "변환 중…" (아티팩트: "3 / 12쪽 변환 중…") |
| 변환 실패 | 문서 목록에 빨간 글씨로 원인 (예: "Office가 설치되어 있어야 합니다") |
| 드래그 중 | 화면 전체 파란 점선 테두리 + "여기에 놓으면 모두에게 공유됩니다" |
| 연결 끊김 | 헤더 상태 점 빨강 + "연결 끊김 — 다시 연결하는 중" |
| 보기 전용 (아티팩트) | 헤더 아래 안내 띠, 도구 모음 숨김 |

## 3. 시각 요소

### 색

| 토큰 | 라이트 | 용도 |
|---|---|---|
| `--bg` | `#eef1f5` | 앱 바탕 |
| `--panel` | `#ffffff` | 헤더·목록·도구 모음 |
| `--line` | `#e2e6ec` | 구분선·테두리 |
| `--text` / `--muted` | `#1f2937` / `#6b7280` | 본문 / 보조 글씨 |
| `--accent` | `#2563eb` | 주요 버튼, 선택 상태, 현재 썸네일 |
| `--danger` / `--ok` | `#dc2626` / `#16a34a` | 오류 / 연결됨·완료 |

- 아티팩트 버전은 같은 구조에 다크 테마 토큰을 추가로 정의 (페이지 자체는 흰색 유지).
- 함께 보기로 공유 중인 다른 페이지 썸네일: 주황 점선 테두리 `#f59e0b`.

### 펜 색 팔레트 (9색)

`#e11d48` 빨강 · `#ea580c` 주황 · `#ca8a04` 황토 · `#16a34a` 초록 · `#0d9488` 청록 · `#2563eb` 파랑 · `#7c3aed` 보라 · `#db2777` 분홍 · `#111827` 검정

- 첫 방문 때 앞 6색 중 하나를 무작위로 배정. 이미 접속한 사람이 쓰는 색이면 비어 있는 색으로 자동 변경 (사용자가 직접 고른 색은 바꾸지 않음).
- 도구 모음 첫 칸은 항상 **내 색** (오른쪽 아래 작은 점 표시). 이름·색 대화상자에서 다른 사람이 쓰는 색은 점선 테두리 + "OOO님이 사용 중" 툴팁.
- 아티팩트 버전의 내 색은 claude.ai 계정 고유 색.

### 굵기·크기

| 도구 | 단계 (페이지 단위, 가로 1000 기준) |
|---|---|
| 펜 | 2 · 4 · 8 |
| 형광펜 | 12 · 22 · 36 (불투명도 0.38) |
| 텍스트 | 16 · 26 · 42 (줄 간격 1.25) |

### 글꼴

- UI: Pretendard → Noto Sans KR → 맑은 고딕 → Apple SD Gothic Neo → system-ui (아티팩트는 IBM Plex Sans KR).
- 필기 텍스트: 시스템 한글 글꼴 (PNG 내보내기에서 같은 글꼴로 그려지도록 웹 글꼴을 쓰지 않음).
- 텍스트 필기는 흰 외곽선(글자 크기의 14%)으로 어두운 배경 위에서도 읽힌다.

### 아이콘

24×24 선 아이콘(두께 2, 둥근 끝). 도구: 화살표(선택), 펜, 형광펜, T(텍스트), 지우개.

## 4. 인터랙션

### 도구

| 도구 | 단축키 | 동작 |
|---|---|---|
| 선택 | V | 필기를 누르면 점선 상자 + 작성자 이름표, 끌어서 이동, Delete로 삭제. 빈 곳을 끌면 화면 이동. 텍스트 더블클릭으로 수정 |
| 펜 | P | 누른 채 그리기. 십자 커서 |
| 형광펜 | H | 반투명 굵은 선 |
| 텍스트 | T | 클릭한 곳에 입력창(점선 테두리, 내 색). 기존 텍스트를 누르면 수정. Esc나 바깥 클릭으로 완료, 비우면 삭제 |
| 지우개 | E | 문지른 필기를 지움 (원 커서) |

- 색·크기를 바꾸면 선택한 필기나 입력 중인 텍스트에도 바로 적용 (되돌리기 가능).
- 색·크기 버튼은 누를 때 입력창 포커스를 뺏지 않는다.

### 공통 조작

| 조작 | 결과 |
|---|---|
| `Ctrl/⌘+Z`, `Ctrl/⌘+Shift+Z`, `Ctrl+Y` | 되돌리기 / 다시 실행 |
| `Ctrl+휠`, `+` `-` `0` | 확대 / 축소 / 맞춤 (포인터 위치 기준 확대) |
| `Space`+끌기, 가운데 버튼 끌기 | 화면 이동 |
| `PageUp` `PageDown` (페이지가 화면에 다 들어오면 방향키도) | 페이지 이동 |
| `Ctrl+V` | 클립보드 이미지 업로드 (`스크린샷-시분초.png`) |

### 실시간 표현

- 다른 사람의 그리는 중인 선: 그대로 실시간 표시, 손을 떼면 확정된 선으로 교체. 6초간 소식이 없으면 사라짐.
- 다른 사람의 커서: 자기 색 화살표 + 이름표, 0.08초 부드럽게 이동, 8초 멈추면 흐리게(35%).
- 입력 중인 텍스트는 글자 단위로 다른 사람에게 보인다.
- 함께 보기: 켜져 있으면 다른 사람이 넘긴 페이지로 자동 이동, 내가 넘기면 모두 따라옴. 새 파일이 변환되면 모두의 화면에 그 첫 페이지가 뜬다.

### 알림 (토스트)

화면 아래 가운데, 3.5초 (오류 6~9초). 종류: 기본(진한 남색), 완료(초록), 오류(빨강).
예: "업로드 중… 45%", "업로드 완료 — 변환이 끝나면 모두의 화면에 표시됩니다", "OOO님이 "보고서.pptx"을(를) 올리는 중입니다…", "초대 링크를 복사했습니다".

## 5. 반응형

| 너비 | 변화 |
|---|---|
| > 760px | 문서 목록 고정(접기 가능), 도구 모음 줄바꿈 |
| ≤ 760px | 문서 목록은 ☰로 여는 겹침 패널(썸네일 누르면 닫힘), 도구 모음 가로 스크롤, 초대 버튼은 아이콘만, 내 이름·연결 문구 숨김 |

- 터치·펜: `touch-action: none`으로 브라우저 스크롤 대신 그리기. 화면 이동은 선택 도구로.

## 6. 문구 원칙

- 사용자가 아는 말로: "보드", "초대 링크", "함께 보기", "내 필기".
- 버튼은 결과를 말한다: "새 보드 만들기", "파일 올리기", "이 페이지의 내 필기 지우기".
- 오류는 원인과 할 일을 함께: "PPT·Word·Excel을 열려면 이 PC에 Microsoft Office나 LibreOffice가 설치되어 있어야 합니다."
- 되돌릴 수 없는 일(문서 삭제, 모든 필기 지우기)은 확인을 받는다. 모든 필기 지우기는 "되돌리기로 복구할 수 있습니다"를 함께 안내.

## 7. 접근성

- 모든 아이콘 버튼에 `title` (아티팩트는 `aria-label`도).
- 키보드 포커스 표시(파란 외곽선 2px).
- `prefers-reduced-motion`이면 애니메이션 제거 (아티팩트).
- 색만으로 구분하지 않도록 선택 시 작성자 이름표를 함께 표시.
