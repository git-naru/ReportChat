# PRD — ReportChat 제품 요구사항

| 항목 | 내용 |
|---|---|
| 제품 | ReportChat (공유 문서 필기 보드) |
| 문서 버전 | 1.0 (2026-10-20) |
| 저장소 | `git-naru/ReportChat`, 브랜치 `claude/quirky-galileo-7x9rmw` |
| 관련 문서 | [TRD](TRD.md) · [DRD](DRD.md) · [인수인계](HANDOVER.md) |

## 1. 배경과 문제

회의나 검토 자리에서 스크린샷, PPT, Excel, Word 자료를 함께 보며 "여기", "이 숫자"라고 짚어야 하는 일이 많다. 지금은 화면 공유를 하면 한 사람만 표시할 수 있고, 메신저로 캡처에 그림을 그려 주고받으면 의견이 흩어진다. 여러 명이 **같은 화면을 보면서 각자 동시에 표시**할 수 있는 도구가 필요하다.

## 2. 목표

1. 파일을 올리면 참여한 모두의 화면에 바로 같은 페이지가 뜬다.
2. 참여자마다 다른 색 펜으로 그리고, 키보드로 텍스트를 입력해 의견을 남긴다.
3. 다른 사람이 그리는 선과 입력하는 글자가 실시간으로 보인다.
4. 설치나 계정 준비 없이 바로 쓸 수 있다.

### 하지 않는 것 (범위 밖)

- 원본 문서(PPT·Excel·Word) 내용 자체의 편집. 필기는 페이지 이미지 위에 겹쳐 그린다.
- 화상·음성 통화, 채팅.
- 로그인, 권한 관리, 조직 관리 (서버 버전).
- 필기를 원본 Office 파일에 다시 써 넣기.

## 3. 사용자

| 사용자 | 상황 | 필요 |
|---|---|---|
| 진행자 | 회의에서 자료를 띄우고 설명 | 파일을 빨리 올리고, 모두를 같은 페이지로 데려가기 |
| 참여자 | 자료를 보며 의견 표시 | 내 색으로 짚기, 글로 코멘트 남기기 |
| 원격 검토자 | 다른 장소에서 같은 자료 검토 | 링크 하나로 들어오기, 나중에 다시 열어도 필기 유지 |

## 4. 핵심 시나리오

1. 진행자가 **새 보드 만들기**를 누르고 **초대 링크 복사**로 링크를 보낸다.
2. 참여자는 링크를 열고 이름과 펜 색을 정한다. 이미 쓰이는 색은 자동으로 피한다.
3. 진행자가 PPT를 끌어다 놓는다. 변환이 끝나면 모두의 화면에 첫 슬라이드가 뜬다.
4. 참여자 A는 빨간 펜으로 수치에 동그라미를 치고, B는 텍스트로 "출처 확인 필요"라고 입력한다. 서로의 펜 끝과 커서가 실시간으로 보인다.
5. 진행자가 다음 페이지로 넘기면 **함께 보기**를 켠 사람은 같이 넘어간다.
6. 회의 후 필기를 포함한 페이지를 PNG로 저장해 보고서에 붙인다. 보드는 다음에 다시 열어도 그대로 남아 있다.

## 5. 기능 요구사항

우선순위: **P0** 없으면 출시 불가 · **P1** 첫 버전에 포함 · **P2** 이후 과제

| ID | 요구사항 | 우선순위 | 상태 |
|---|---|---|---|
| F-01 | 새 보드 생성, 초대 링크 복사, 링크로 참여 | P0 | 완료 |
| F-02 | 이미지(png·jpg·gif·webp·bmp) 업로드 | P0 | 완료 |
| F-03 | `Ctrl+V` 스크린샷 붙여넣기, 드래그&드롭 업로드 | P0 | 완료 |
| F-04 | PDF 업로드 (쪽마다 페이지) | P0 | 완료 |
| F-05 | PPT·Word·Excel 업로드 (Excel은 시트당 한 페이지) | P0 | 완료 (서버·Windows 버전) |
| F-06 | 올린 문서가 모든 참여자 화면에 자동 표시 | P0 | 완료 |
| F-07 | 펜·형광펜, 색 9가지, 굵기 3단계 | P0 | 완료 |
| F-08 | 참여자별 기본 펜 색, 겹치지 않게 자동 배정 | P0 | 완료 |
| F-09 | 키보드 텍스트 입력(여러 줄), 크기 3단계, 기존 텍스트 수정 | P0 | 완료 |
| F-10 | 그리는 중인 선·입력 중인 글자 실시간 공유 | P0 | 완료 |
| F-11 | 다른 참여자 커서와 이름표 표시 | P1 | 완료 |
| F-12 | 선택·이동, 삭제, 지우개 | P1 | 완료 |
| F-13 | 되돌리기/다시 실행 (내 작업만) | P1 | 완료 |
| F-14 | 페이지의 내 필기 / 모든 필기 지우기 | P1 | 완료 |
| F-15 | 함께 보기 (페이지 이동 동기화, 끄기 가능) | P1 | 완료 |
| F-16 | 확대/축소, 화면 이동 | P1 | 완료 |
| F-17 | 필기 포함 페이지 PNG 저장 | P1 | 완료 |
| F-18 | 보드 상태 저장, 재접속 시 복원, 끊긴 동안의 편집 재전송 | P1 | 완료 |
| F-19 | 문서 삭제 (그 위 필기 포함) | P1 | 완료 |
| F-20 | 모바일·태블릿 화면 지원 (터치·펜 입력) | P1 | 완료 |
| F-21 | 전체 페이지를 PDF 한 파일로 내보내기 | P2 | 미구현 |
| F-22 | 보드 접근 권한 (비밀번호·로그인) | P2 | 미구현 |
| F-23 | 채팅·댓글 패널 | P2 | 미구현 |
| F-24 | HWP 지원 | P2 | 미구현 |

## 6. 배포 형태

| 형태 | 대상 | 특징 |
|---|---|---|
| 서버 버전 (Node.js) | 사내 서버, 개발자 PC | `npm start`. Office 변환에 LibreOffice 필요 |
| Windows 포터블 | 일반 사용자 PC | zip 풀고 `ReportChat.cmd` 더블클릭. Node 포함, Office는 설치된 MS Office 사용 |
| Docker | 서버 운영 | LibreOffice·한글 글꼴 포함 |
| claude.ai 아티팩트 | 설치 없이 바로 | 링크로 열기. 이미지·PDF만, 참여자는 편집자로 초대 필요 |

## 7. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 실시간성 | 다른 사람의 선이 그려지는 동안 보임 (전송 주기 40ms), 커서 50ms |
| 변환 시간 | 이미지 즉시, PDF 쪽당 1초 안팎, Office 문서 수 초 (LibreOffice 첫 실행은 더 걸림) |
| 업로드 한도 | 파일당 100MB (설정 가능), 문서당 200쪽 |
| 동시 사용 | 한 보드에 수십 명 수준 (단일 서버 프로세스) |
| 브라우저 | 최신 Chrome, Edge, Safari, Firefox |
| 데이터 보존 | 서버 디스크(`DATA_DIR`)에 무기한 보관 |

## 8. 성공 지표

- 파일을 올린 뒤 모든 참여자 화면에 뜨기까지 이미지·PDF 5초 이내, Office 30초 이내.
- 회의 1건에서 2명 이상이 필기를 남긴 보드의 비율.
- 같은 보드 재방문율 (회의 후 다시 열어 보는지).

## 9. 위험과 제약

| 위험 | 영향 | 대응 |
|---|---|---|
| 링크만 알면 누구나 접속 | 민감 문서 노출 | 내부망 사용 권장, 추측 어려운 무작위 주소. 인증은 P2 |
| 메일 첨부 차단 | Windows zip(56MB, 실행 파일 포함)은 메일로 못 보냄 | 릴리스 다운로드 링크로 공유 |
| Office 변환 품질 | 특수 글꼴·애니메이션이 원본과 다름 | 안내 문구, PDF로 저장 후 올리기 권장 |
| 동시 편집 충돌 | 같은 객체를 동시에 고치면 나중 것이 남음 | 필기는 객체 단위라 충돌이 드묾. 범위 내 허용 |
