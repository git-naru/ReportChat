ReportChat - Windows 버전
==========================

스크린샷, PDF, PowerPoint, Excel, Word 파일을 올리면 같은 네트워크의 여러 사람이
같은 화면을 보며 각자의 색 펜과 키보드 텍스트로 함께 표시할 수 있습니다.
설치는 필요 없습니다.


■ 실행
1. 이 폴더를 원하는 곳(예: 바탕화면, 문서)에 둡니다. 압축을 푼 상태여야 합니다.
2. ReportChat.cmd 를 더블클릭합니다.
   - "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 누릅니다.
   - "Windows 보안 경고(방화벽)" 창이 뜨면 [개인 네트워크]에 체크하고 [액세스 허용]을 누릅니다.
     이걸 허용해야 다른 사람이 접속할 수 있습니다.
3. 브라우저가 자동으로 열립니다. [새 보드 만들기]를 누르세요.
4. 검은 창에 나온 "같은 네트워크의 다른 사람은 이 주소로 접속합니다: http://192.168.x.x:3000" 주소를
   함께 쓸 사람에게 알려 주거나, 보드 안의 [초대 링크 복사]로 링크를 보낸 뒤
   localhost 부분을 그 IP로 바꿔서 보내면 됩니다.

검은 창(ReportChat)을 닫으면 프로그램이 꺼집니다. 쓰는 동안은 열어 두세요.


■ 파일 형식
- 이미지(스크린샷): png, jpg, gif, webp, bmp — 바로 됩니다. 보드에서 Ctrl+V로 붙여넣을 수도 있습니다.
- PDF — 바로 됩니다.
- PowerPoint, Word, Excel — 이 PC에 Microsoft Office가 설치되어 있으면 Office로 변환합니다.
  Office가 없으면 LibreOffice(무료, https://www.libreoffice.org)를 설치하면 됩니다.
  Excel은 시트 하나가 한 페이지가 됩니다.


■ 저장
보드와 필기는 이 폴더 안의 data 폴더에 저장됩니다. 프로그램을 다시 켜도 그대로 남아 있습니다.
폴더를 옮길 때 data 폴더도 함께 옮기세요.


■ 문제 해결
- 다른 사람이 접속이 안 될 때
  · 같은 Wi-Fi / 사내망에 있는지 확인하세요. 휴대폰은 LTE·5G를 끄고 Wi-Fi로 접속하세요.
  · 제어판 → Windows Defender 방화벽 → 앱이 방화벽을 통과하도록 허용 → "Node.js" 또는 "node"를 찾아
    [개인]과 [공용]에 체크하세요.
  · 회사 망은 PC끼리의 접속을 막아 두기도 합니다. 이 경우 IT 담당자에게 문의하세요.
- "포트 3000을 이미 다른 프로그램이 쓰고 있습니다"가 나올 때
  · ReportChat이 이미 켜져 있는지 확인하세요(작업 표시줄의 검은 창).
- PPT·Word·Excel이 "변환하지 못했습니다"로 나올 때
  · 그 파일이 Office에서 열려 있으면 닫고 다시 올려 보세요. 암호가 걸린 파일은 열 수 없습니다.
